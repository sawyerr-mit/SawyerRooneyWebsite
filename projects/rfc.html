Hazardous asteroid classifier

A Random Forest that predicts whether an asteroid is potentially hazardous, trained on about 10,000 objects from NASA's NeoWs API.

  • Python
  • pandas
  • scikit-learn
  • REST APIs
Downloads View on GitHub

Overview

The notebook pages through NASA's NeoWs API, flattens the JSON into a pandas DataFrame, drops the few rows with missing values and trains a Random Forest on five features: absolute magnitude, minimum and maximum estimated diameter, relative velocity and miss distance.

Hazardous asteroids are rare, so the forest weights that class 50 to 1. That trades some overall accuracy for much better recall on the class that matters. On the validation split it flagged 60 of 72 hazardous asteroids (83.3%) and cleared 1,766 of 1,925 non-hazardous ones (91.7%).

Based on CIS 454 (AI and Advanced Python) Assignment 4, University of Maine at Augusta, Spring 2026.

Highlights

  • Pulled and flattened roughly 10,000 asteroid records from NASA's REST API with requests and pandas.
  • Weighted the hazardous class 50 to 1 to favor recall on the rare class that matters.
  • Flagged 60 of 72 hazardous asteroids (83.3%) on the held-out 20% validation split.
