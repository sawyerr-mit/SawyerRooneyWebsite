QR algorithm polynomial solver

Finds polynomial roots as the eigenvalues of a companion matrix, using an iterative QR algorithm.

Overview

Polynomial coefficients are turned into a companion matrix, whose eigenvalues are the polynomial's roots. The QR algorithm then repeatedly factors the matrix as A = QR and forms RQ. After enough iterations the diagonal converges to the eigenvalues, so every root is found at the same time.

The iteration is written by hand and each factorization uses NumPy's np.linalg.qr. The included example is a degree-7 polynomial with coefficients 1, −28, 322, −1960, 6769, −13132, 13068, −5040, whose roots are the integers 1 through 7.

import numpy as np

# This generates a matrix whose eigenvalues are equivalent to the roots of a polynomial
# with given coefficients. To understand how this works, see:
# https://en.wikipedia.org/wiki/Companion_matrix
def companion_matrix(coeffs):
    coeffs = np.asarray(coeffs, dtype=float)

    if len(coeffs) < 2:
        raise ValueError("Polynomial must have degree >= 1.")

    coeffs = coeffs / coeffs[0]
    n = len(coeffs) - 1

    C = np.zeros((n, n))
    C[1:, :-1] = np.eye(n - 1)
    C[:, -1] = -coeffs[1:][::-1]

    return C

# This algorithm is simple to implement, but has considerable
# perfomance benefits to basic guess and check methods.
# The general theory of this algorithm is very similar to the 
# method of power iteration, but isolates all eigenvalues
# simultaneously rather than only the largest eigenvalue.
# To understand how this works, see:
# https://en.wikipedia.org/wiki/QR_algorithm
def QR_Algorithm(A):
    Ak = A.copy()
    for _ in range(1000):
        Q, R = np.linalg.qr(Ak)
        Ak = R @ Q
    return np.diag(Ak)

# The coeffs list encodes the polynomial, change the coeffs to solve desired polynomial.
if __name__ == "__main__":
    coeffs = [1, -28, 322, -1960, 6769, -13132, 13068, -5040]
    C = companion_matrix(coeffs)

    np.set_printoptions(precision=0, suppress=True, floatmode='fixed')

    print("Coefficients:", coeffs)
    print("Companion matrix:\n", C)
    print("Eigenvalues:", QR_Algorithm(C))
